Méthodologie

Inférences et modèles

Spatial joins

Croisement géométrique entre transactions DVF (points), polygones IRIS et empreintes bâti cadastre — sans geopandas, juste shapely.prepared pour la performance.

Modèle de probabilité de vente 12 mois

Régression logistique (sklearn) calibrée sur l'historique DVF × DPE. Score par logement basé sur l'étiquette énergie, l'âge du bâti, l'activité de la rue, le quartier.

Projection ARIMA + bootstrap

Modèle temporel sur le prix médian mensuel, avec intervalle de confiance par bootstrap des résidus (5000 itérations).

Audit factualité des notes IA

Chaque chiffre cité dans une analyse rédigée par LLM est automatiquement recoupé contre la donnée source. Un score % indique combien de chiffres ont été retrouvés.

Garanties

  • · Aucun scraping : toutes les données proviennent d'APIs publiques ou de bulk downloads officiels.
  • · Aucune donnée personnelle : les analyses se font à l'échelle IRIS (~2000 habitants), jamais nominative.
  • · Code source ouvert : le pipeline Python et le frontend Next.js sont consultables (open source).
  • · Conformité RGPD : pas de cookies tiers, pas de tracking, pas de transfert vers serveur tiers.
  • · Audit factualité automatique : chaque chiffre cité dans les notes IA est recoupé contre la source.
La Carte Prelys est mise à disposition gratuitement à titre démonstratif. Les données sont indicatives et doivent être recoupées par un professionnel avant tout engagement contractuel (compromis, mandat, conseil en investissement).
